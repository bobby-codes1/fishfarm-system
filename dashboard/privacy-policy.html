Privacy Policy

Last updated: May 2026

What Data We Collect

We collect the following data from users of this system:

  • WhatsApp phone numbers of farm workers and the farm owner
  • Daily feeding logs — pond name, feed type, and quantity (kg)
  • Fish count and mortality records per pond
  • Harvest records — weight, fish count, buyer, and sale price
  • Feed inventory levels and restocking information

No personal names, addresses, payment card details, or other sensitive personal information are collected.

How We Use It

All data collected is used exclusively to operate the fish farm inventory management system:

  • Processing WhatsApp commands from farm workers (feeding, mortality, harvest logs)
  • Sending automated alerts and daily reports to the farm owner via WhatsApp
  • Generating weekly AI-powered farm performance analysis
  • Displaying the farm dashboard with real-time stock and pond status

We do not use your data for marketing, profiling, or any purpose beyond managing farm operations.

Data Storage and Security

All farm data is stored in a secure, cloud-hosted PostgreSQL database provided by Supabase. Access is restricted to the server application using an encrypted service role key. The database is not publicly accessible.

Data is retained for as long as the farm system is in active use. You may request deletion of your data at any time by contacting us using the details below.

Third Party Services

This system uses the following third-party services to function:

  • Supabase — database hosting and storage (supabase.com/privacy)
  • Meta WhatsApp Cloud API — message delivery to and from farm workers (facebook.com/privacy/policy)
  • Anthropic Claude API — generating weekly farm analysis reports (anthropic.com/privacy)
  • Railway — application hosting (railway.app/legal/privacy)

Farm operational data is shared with these services only to the extent required to deliver their function. No data is sold or shared with any other third party.
